## 🚀 Oopz Desktop v0.2.0

### ✨ 新增功能 (Key Features)

- 在「语音 → 麦克风自检」中选择输入设备、查看实时电平。测试在 10 秒后自动停止，也可手动结束。
- 可为下次麦克风请求启用降噪和回声消除偏好，保留官网明确指定的参数。Windows 声音设置和麦克风隐私设置也可从「语音」菜单打开。
- 从「页面」菜单点选要隐藏的独立图片，或一键恢复。客户端仍然直接加载官方 Oopz 网页。
- 隐藏到 Windows 托盘时，客户端会通知 WebView2 隐藏页面，并在支持的运行时上请求降低内存使用目标。再次启动可恢复原窗口。
- 窗口菜单支持重新加载（Ctrl+R）和完全退出（Ctrl+Q）。

### 📦 安装说明 (Installation)

| Windows x64 文件 | 用途 |
| --- | --- |
| `oopz_0.2.0_x64-setup.exe` | 常规安装，下载后运行安装向导。 |
| `oopz_0.2.0_x64.msi` | 使用 Windows Installer 安装或部署。 |
| `oopz_0.2.0_x64-portable.zip` | 完整解压后运行 oopz.exe，需要系统已安装 Microsoft Edge WebView2 Runtime。 |

### 🛠️ 技术说明 (Technical Details)

客户端基于 Rust、Tauri 2 和 WebView2。Windows x64 安装包与便携包由 GitHub Actions 从同一个版本标签构建。麦克风处理效果取决于设备、运行时和官网的采集设置。

本项目是非官方客户端，与 Oopz 官方无关。可通过 [Issues](https://github.com/Ktclat/Oopz-Desktop-Unofficial-Client/issues) 反馈问题。
