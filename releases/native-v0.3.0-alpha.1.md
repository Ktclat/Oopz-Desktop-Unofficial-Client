## Windows 原生客户端首次预览

本版提供独立的 WPF 桌面程序，主窗口、频道列表、消息和麦克风测试均在本机运行。需要 Windows 10/11 x64 及 .NET Framework 4.8。

- 已有本机 Oopz OneBot v11 适配器时，点「连接适配器…」，填写端口和可选的适配器令牌。连接后可选择频道、查看近期事件、接收新消息和发送纯文本。
- 点「打开网页记录…」可在本机只读查看自己导出为 HAR 的域、频道和文字记录。
- 点「麦克风自检…」选择输入设备，观察音量。10 秒后自动结束，也可随时停止。

解压 `oopz_0.3.0-alpha.1_x64-native-portable.zip`，运行 `Oopz.Native.exe`。账号授权和实际收发依赖已配置的适配器。个人账号直接登录及官方语音房通话仍在接入验证阶段。

Windows Actions 使用本机测试服务验证文字收发。该检查不需要真实 Oopz 账户。
